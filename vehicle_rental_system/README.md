# Vehicle Rental Management System

A console-based Python application with a MySQL database for managing
vehicles, customers, bookings and billing.

## Features
- Vehicle management (add, view, search, filter, update rate, update status, delete)
- Customer management (add, view, search, update, delete) with validation:
  10-digit phone number, valid email, driving licence with letters and numbers
- Bookings with double-booking prevention. You choose a current booking
  (starts today automatically, status ACTIVE) or a future booking (you enter
  the start date, status RESERVED), and enter the security deposit
- Bills with a late fee (only if the customer was late) and 18% GST
- Simple numeric IDs (1, 2, 3, ...) generated by MySQL; an ID never changes

## Billing rules
```
Rental amount = daily rate x rental days
Late fee      = days late x daily rate   (0 if the customer was on time)
GST (18%)     = 18% of (rental amount + late fee)
Total due     = rental amount + late fee + GST
```

## Setup
1. Install MySQL and create the tables: `mysql -u root -p < schema.sql`
   (if you have an older version of the database, first run
   `mysql -u root -p -e "DROP DATABASE vehicle_rental;"` - this deletes its data)
2. Create a database user (see the bottom of `schema.sql`)
3. Install packages: `pip install -r requirements.txt`
4. Copy `.env.example` to `.env` and fill in your database password
5. Run the program: `python main.py`

## Project structure

```
utils.py         input validation and table display
schema.sql       database tables
modules/
    vehicle.py   vehicle management
    customer.py  customer management
    booking.py   booking logic
    billing.py   bill generation and payments
```
